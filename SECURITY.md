# Security Policy

## Supported versions

Security fixes are provided for the latest released version of ComfyUI-MiniMaxH3-CLIPCached.

Users are encouraged to update to the latest release before reporting a security issue.

## Reporting a vulnerability

Please report security vulnerabilities using GitHub's **Private Vulnerability Reporting** feature for this repository.

Do not open a public issue for vulnerabilities that could expose:

- credentials, tokens, or API keys,
- private data,
- arbitrary code execution,
- path traversal or unintended file access,
- other security-sensitive implementation details.

When reporting a vulnerability, include enough information to reproduce and understand the issue, but remove unrelated private prompts, local paths, credentials, and personal data from logs.

Please allow reasonable time for investigation before publicly disclosing the vulnerability.

## General bug reports

Normal bugs that do not have security implications should be reported through the repository's public issue tracker.
